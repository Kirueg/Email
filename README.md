# Веб-приложение почты

Курсовая работа: Веб-приложение для обмена и управления электронными сообщениями.

## О проекте

Это сервис почты, разработанный как курсовая работа.
Проект был взят на переработку и переосмысление с целью доработки
функциональности и улучшения качества кода: переписывания устаревших
компонентов, приведения типов, исправления архитектурных решений и
приведения интерфейса к единому стилю.
